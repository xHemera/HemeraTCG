# Social Icons

Place your social media icon images here.

## Recommended format
- **Format**: PNG with transparency
- **Size**: 32x32px or 64x64px (for HD screens)
- **File size**: < 10KB per image

## Required images
- `instagram.png`
- `discord.png`
- `league.png`
- `silentlab.png`

You can download free icons from:
- [Icons8](https://icons8.com)
- [Flaticon](https://www.flaticon.com)
- [Font Awesome](https://fontawesome.com)
